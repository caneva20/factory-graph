# Capacity-Driven Single Node

The capacity-driven single-node scenario compares one expected product rate with machine activity limits below and above that rate. Both cases maximize physical output; the result reports either a target deficit or target surplus against the expected rate.

Coverage:

- Graph shape: single node.
- Planning mode: capacity-driven.
- Objective: maximize target output.
- Constraint: machine-group activity capacity.
- Resource conditions: target deficit and target surplus.
- Status: optimal.
